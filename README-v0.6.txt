Silvana Career Agent v0.6
Автоподготовка отклика без рабочего компьютера

Сценарий:
1. VPS ищет вакансии каждые 3 часа.
2. Открывает полное описание.
3. Пересчитывает Match Score по полному тексту.
4. Для подходящих вакансий пишет отдельное сопроводительное.
5. Открывает форму отклика в облачном HH-браузере.
6. Выбирает резюме, если выбор однозначен.
7. Вставляет сопроводительное.
8. НЕ нажимает финальную отправку.
9. После подготовки пишет в Telegram.
10. Кнопка «Проверить и отправить» фокусирует нужную вкладку.

Ограничения безопасности:
- одновременно в очереди максимум 5 форм;
- за один цикл готовится максимум 2;
- вакансии с переездом, командировками или нерелевантной ролью блокируются;
- вопросы работодателя не заполняются выдуманными ответами;
- при капче бот просит открыть облачный браузер;
- автоотправки нет.

Установка:
1. Распаковать содержимое поверх репозитория.
2. Загрузить файлы в GitHub.
3. На VPS:

cd /opt/career-agent-src
git pull
chmod +x deploy/install-v0.6.sh
bash deploy/install-v0.6.sh

Во время настройки токен BotFather вводится скрыто.
Если Telegram уже подключён, скрипт использует существующий .env.

Проверка:
curl http://127.0.0.1:8010/health
journalctl -u career-agent-worker -n 100 --no-pager
